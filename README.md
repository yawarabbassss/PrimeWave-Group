# Primewave Group of Companies

> Results-driven business process outsourcing (BPO) group partnering with US-based businesses to build systems, scale operations, and deliver measurable performance.

Backed by a team of 200+ professionals across:
- **NationWide Enterprises**: Freight brokerage and carrier logistics operations ([nationwideenterprises.net](https://nationwideenterprises.net))
- **Sky Dispatch LLC**: Premier 24/7 US freight dispatching for owner-operators and fleets ([skydispatch.net](https://skydispatch.net))
- **Primewave Services**: Full-service short-term rental (Airbnb & Vrbo) property management ([primewaveservices.com](https://primewaveservices.com))
- **Bookkeeping Services**: Comprehensive QuickBooks, accounts payable/receivable, payroll, and financial reporting

## Features
- **Cinematic Scrollytelling Hero**: Interactive sticky scroll journey highlighting corporate divisions, core mission, and KPIs.
- **Dynamic Orbital Ecosystem**: Balanced equilateral 3-point planetary animation revolving around the central Primewave core with zero overlaps.
- **Multi-Page Architecture**:
  - `index.html`: Main scrollytelling portal and service breakdown
  - `companies.html`: Detailed operating division profiles & live links
  - `leadership.html`: Executive leadership philosophy and oversight
  - `about.html`: Heritage, US alignment, and Lahore operational hub
  - `careers.html`: Open career opportunities for 200+ team members
  - `blogs.html`: Industry playbooks and operational insights
  - `contact.html`: Partner with us & consultation portal
- **Responsive & Modern Design System**: Built with CSS custom properties, Cormorant Garamond serif headings, Plus Jakarta Sans typography, luxury teal (`#1D7C74`) and slate (`#232D33`) palettes, and accessible UI controls.

## Development & Local Preview
This site runs out of the box with any static HTTP server or PHP built-in server:
```bash
# Using PHP built-in server
php -S localhost:8000

# Using Python
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.
